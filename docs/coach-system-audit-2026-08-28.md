## P0 — Lifecycle dead-ends (the CIM build blocker)

1. **Recovery→build handoff is a dead letter.** `plan-drift` cron detects `recovery_complete` but only writes a pending card (`TURNED OFF · 2026-08-26`); runner has answered 0 of 40 engine cards ever (39 expired). Card re-mints nightly (24h dedupe). Fallback copy says the block "was built" — past tense, false. Fix: auto-handoff via `fireAutoRebuild` (undoable, coach note), card becomes a record not a gate.
2. **Race-anchored maintenance hold block that elapses is re-authored by nothing** — documented in-code (`generate.ts:6976`) and as registry exemption `MAINTENANCE.hold-block-length`. Fix: teach the elapsed branch to re-author race-anchored blocks; delete exemption.
3. **Injury plan elapses → goal build auto-authored over an injured runner.** `plan_elapsed` branch has no `runnerIsCompromised` guard (injury plans write `mode='maintenance'`, `race_id=NULL`, so they match). Fix: guard.
4. **Recovery plan with null race_date → no re-entry at all.** `recoveryCompleteDue` returns false; `plan_elapsed` gated on `!race_id`. Fix: fallback path.
